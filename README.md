# Portafolio de Cindy Marin

> Basado en la plantilla [career-portfolio-template](https://github.com/nbakh16/career-portfolio-template) de [@nbakh16](https://github.com/nbakh16).

![Astro](https://img.shields.io/badge/Astro-FF5D01?logo=astro&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-06B6D4?logo=tailwindcss&logoColor=white)

Portafolio personal como desarrollador fullstack. Muestra experiencia laboral, cursos, certificaciones y proyectos personales construidos con **Javascript/TypeScript**, **React**, **NextJS**, **Angular**, **Astro**, **NestJS/NodeJS** y **Laravel-Symfony/PHP**. Rápido, estático y basado en datos.

## 🚀 Stack

- **Framework:** Astro (SSG)
- **Estilos:** Tailwind CSS
- **Despliegue:** Vercel

## 📁 Personalización

Todo el contenido personal vive en `src/data/` — sin necesidad de tocar los componentes.

## 🛠️ Correr localmente

```bash
pnpm install
pnpm run dev
```
